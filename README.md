“JavaScript dan jQuery”

jawaban : 
1. JavaScript adalah bahasa pemrograman tingkat tinggi yang berjalan langsung di browser dan digunakan untuk membuat halaman web menjadi interaktif. JavaScript juga dapat dijalankan di sisi server melalui Node.js.
Kegunaan utamanya:
Memanipulasi elemen HTML dan CSS pada halaman (DOM).
Menangani event pengguna, seperti klik, input, dan pengiriman form.
Memvalidasi data form sebelum dikirim ke server.
Mengambil dan mengirim data ke server tanpa memuat ulang halaman (AJAX/fetch).
Membuat fitur dinamis, seperti animasi, slider, dan notifikasi.
2.jQuery adalah library JavaScript yang ringan dan dibuat untuk menyederhanakan penulisan kode JavaScript. Dengan semboyan “write less, do more”, jQuery menyediakan fungsi siap pakai sehingga kode menjadi lebih singkat.
Kegunaan utamanya:
Memilih elemen HTML dengan selector seperti CSS, misalnya $("#kotakWarna").
Memanipulasi DOM dan CSS, misalnya .css(), .hide(), dan .show().
Menangani event dengan sintaks ringkas, misalnya .click().
Membuat efek animasi, seperti fadeIn() dan slideUp().
Melakukan AJAX dengan sintaks yang lebih sederhana dan kompatibel di berbagai browser.
3.perbedaan  nya ada pada jenis nya dimana js merupakan bahasa pemograman sedangkan jquery menggunakan library yang dibangun diatas javaScript, perbedaan nya terletak pada instalasinya dimana js nya bawaan browser tidak perlu tambahan, sedangkan jquery harus dimuat terlebih dahulu melalui cdn atau file lokal
